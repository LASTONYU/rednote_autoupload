小红书图片定时发布助手 v1.0
这是一个基于 Python 和 Playwright 开发的轻量级自动化工具，旨在帮助创作者实现小红书笔记的定时自动发布与多账号登录管理。

核心功能
定时自动发布：设定每日固定时间，程序自动读取文件夹内第一张图片进行发布。

资源归档：发布成功后，图片会自动移动到上级目录并重命名，防止重复发布。

后台静默运行：支持最小化到系统托盘，不占用任务栏空间。

单实例检测：防止多次开启程序导致进程冲突。

登录态保持：基于 Edge 浏览器环境，扫码一次后长期免密登录。

文件结构说明
为了保持程序运行稳定，请确保文件夹内包含以下必要项：

使用指南
1. 准备工作
确保电脑已安装 Microsoft Edge 浏览器。

准备一个专门存放待发布图片的文件夹（支持 .jpg, .png, .jpeg）。

2. 首次运行
双击运行 小红书助手v1.0.exe。

在界面中点击 “浏览”，选择你的图片文件夹。

填写默认的 发布标题、详情正文 和 话题标签（多个标签用英文逗号隔开）。

设定 每日发布时间。

点击 “保存配置”。

3. 登录账号
点击 “立即发布一次”，程序会唤起浏览器。

如果是首次使用，请在弹出的浏览器窗口中完成小红书网页版扫码登录。

注意：登录成功后，只要不删除 edge_profile_data 文件夹，后续发布均无需再次扫码。

4. 后台运行
点击窗口右上角的 [X]，程序将自动缩至系统右下角托盘区。

如需彻底关闭，请在托盘图标上点击右键 -> 彻底退出。

常见问题 (FAQ)
Q：为什么杀毒软件会报毒？ A：本程序使用了自动化控制脚本和文件锁定机制，部分杀毒软件会将其识别为敏感行为。请点击“允许”或将程序所在目录加入白名单。

Q：如何设置开机自启动？

在程序界面勾选“开机自启动指引”。

按照弹出的窗口提示，将程序的快捷方式放入系统启动文件夹（shell:startup）即可。

Q：发布失败了怎么办？

检查网络连接是否正常。

确认 Edge 浏览器是否为最新版本。

查看程序底部的日志框，获取具体错误原因。
