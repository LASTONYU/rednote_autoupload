# 小红书定时上传工具

一个可以每天定时上传图片到小红书的Python小程序，支持选择图片文件夹，程序会按顺序每天自动上传一张图片，支持在程序端编辑文案和设置上传选项。

## 功能特点

- 📁 **文件夹选择**：支持从本地电脑选择图片文件夹，程序自动扫描并按顺序上传
- 📸 **按序上传**：每天从文件夹中选取下一张图片上传，循环执行
- 📝 **文案编辑**：支持自定义小红书笔记文案
- 🏷️ **标签管理**：支持添加多个标签，用逗号分隔
- ⏰ **定时上传**：可以设置每天的上传时间，自动执行
- 💾 **配置保存**：自动保存用户配置和当前上传进度，下次启动自动加载
- 📊 **状态显示**：实时显示当前程序状态和上传结果
- 📤 **图片自动归档**：上传成功后，图片会自动移动到上一级文件夹，便于管理
- 🤖 **自动退出**：定时上传完成后，程序会自动退出，适合通过系统任务计划程序运行

## 环境要求

- Python 3.7 或更高版本
- Windows/Linux/macOS

## 安装依赖

1. 克隆或下载项目到本地
2. 打开命令行终端，进入项目目录
3. 安装所需依赖：

```bash
pip install -r requirements.txt
```

## 使用方法

### 1. 安装Playwright浏览器

在使用本工具之前，您需要先安装Playwright及其浏览器：

```bash
# 安装Playwright
pip install playwright

# 安装浏览器（首次使用时需要执行）
playwright install
```

### 2. 运行程序

在命令行终端中执行：

```bash
python xiaohongshu_uploader.py
```

### 3. 配置程序

1. **选择图片文件夹**：点击"浏览"按钮选择要上传的图片文件夹
2. **编辑文案**：在"文案"文本框中输入小红书笔记的文字内容
3. **添加标签**：在"标签"输入框中输入标签，多个标签用逗号分隔
4. **设置定时**：
   - 在"每天上传时间"输入框中设置上传时间（格式：HH:MM）
   - 勾选"启用定时上传"复选框
5. **保存配置**：点击"保存配置"按钮保存当前设置

### 4. 执行上传

- **立即上传**：点击"立即上传"按钮，程序会启动浏览器并自动执行以下操作：
  1. 打开小红书创作者平台发布页面
  2. 等待您手动登录（首次使用时）
  3. 从选定的文件夹中选择下一张图片上传
  4. 自动输入预设的文案
  5. 自动添加预设的标签
  6. 点击发布按钮完成上传
  7. 上传成功后，图片会自动移动到上一级文件夹

- **定时上传**：程序会在设置的时间自动执行上述上传流程
  - 定时上传完成后，程序会自动退出
  - 适合通过系统任务计划程序运行，无需人工干预

## 配置文件

程序会在项目目录下生成 `config.json` 文件，保存用户配置和上传进度。您可以手动编辑此文件来修改配置，也可以在程序中修改后保存。

配置文件格式：

```json
{
  "upload_time": "08:00",
  "caption": "默认文案",
  "tags": "标签1,标签2,标签3",
  "enable_schedule": true,
  "image_folder": "C:\\Users\\YourName\\Pictures\\Xiaohongshu",
  "current_image_index": 0
}
```

## 注意事项

1. **Playwright初始化**：
   - 首次使用前必须执行 `playwright install` 安装浏览器
   - 确保网络连接正常，以便Playwright下载浏览器

2. **登录说明**：
   - 首次运行程序时，需要手动在弹出的浏览器中登录小红书账号
   - 登录后，Playwright会保存登录状态，后续运行无需再次登录
   - 请确保在登录后关闭浏览器，以便程序保存登录状态

3. **图片要求**：
   - 小红书对上传图片有尺寸和格式要求，请确保您的图片符合要求
   - 推荐使用正方形图片，尺寸不小于720x720像素
   - 支持的图片格式：JPG、JPEG、PNG、GIF

4. **安全提示**：
   - 程序仅在本地运行，不会将您的信息上传到第三方服务器
   - 浏览器登录状态保存在本地，请注意保护您的电脑安全

5. **程序运行**：
   - 手动运行时，程序会保持打开状态，直到用户手动关闭
   - 定时上传时，程序会在上传完成后自动退出
   - 浏览器会在每次上传完成后自动关闭

6. **发布说明**：
   - 程序会自动点击发布按钮完成实际发布
   - 发布前请仔细检查文案和标签是否正确
   - 发布成功后，图片会自动移动到上一级文件夹

7. **小红书页面变化**：
   - 由于小红书网站可能会更新页面结构，程序中的选择器可能会失效
   - 如果遇到上传失败，请检查并更新代码中的CSS选择器
   - 程序会自动保存调试信息到当前目录，便于排查问题

## 常见问题

### Q: 上传失败怎么办？
A: 请检查以下几点：
   1. 访问令牌是否有效
   2. 图片文件是否存在
   3. 网络连接是否正常
   4. 查看程序底部的状态提示，了解具体错误信息

### Q: 定时上传不执行怎么办？
A: 请检查以下几点：
   1. 是否勾选了"启用定时上传"复选框
   2. 上传时间设置是否正确
   3. 程序是否保持运行状态
   4. 配置是否已保存

### Q: 如何修改上传时间？
A: 在程序中修改"每天上传时间"，然后点击"保存配置"按钮即可
